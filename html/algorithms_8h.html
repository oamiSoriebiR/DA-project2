bool runBasicAlgorithm ( Graph< int > & graph,
std::vector< Web > & webs,
int k )

Runs the basic register allocation algorithm using graph coloring. It attempts to color the graph without any spilling or splitting.

Parameters
graphThe interference graph representing the webs.
websVector of Web structures to allocate registers for.
kThe number of available registers (colors).
Returns
True if allocation succeeded without spilling, false otherwise.
Note
Time Complexity: O(V^2 + V*k), where V is the number of vertices (webs) and k is the number of registers.

◆ runSpillingAlgorithm()

bool runSpillingAlgorithm ( Graph< int > & graph,
std::vector< Web > & webs,
int k )

Runs the register allocation algorithm with support for spilling to memory. If the basic algorithm fails, it iteratively spills the most suitable webs until the graph is colorable.

Parameters
graphThe interference graph representing the webs.
websVector of Web structures to allocate registers for.
kThe number of available registers (colors).
Returns
Always returns true as uncolorable webs are spilled to memory.
Note
Time Complexity: O(V^2 * W + W^2 * L), where V is the number of vertices, W is the number of webs, and L is the max number of lines in a web.

Runs the register allocation algorithm with support for web splitting. If the graph cannot be colored, it attempts to split webs into smaller segments to reduce interference.

Parameters
graphThe interference graph.
websVector of Web structures.
kThe number of available registers.
Returns
True if allocation succeeded, either natively or by successfully splitting webs.
Note
Time Complexity: O(C * (W^2 * L + V^2)), where C is a constant max splits, W is the number of webs, L is the max lines per web, and V is the number of vertices.

◆ splitWeb()

bool splitWeb ( std::vector< Web > & webs,
int victimId )

Splits a web into two smaller webs at the point where interference ends, to increase colorability.

Parameters
websThe vector of Web structures. The newly created web fragment is appended to this list.
victimIdThe ID of the web to split.
Returns
True if the web was successfully split, false if it could not be split (e.g., only 1 line).
Note
Time Complexity: O(W * L * log(L)), where W is the number of webs and L is the number of lines in the victim web.
